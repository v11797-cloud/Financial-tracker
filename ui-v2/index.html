분류·날짜 기준

오늘 게시와 수집 시각

오늘은 한국시간(KST) 기준입니다. ‘오늘 게시’는 데이터의 게시일·공포일·제개정일(협회 예고는 예고시작일)이 오늘인 항목 수이며, 오늘 새로 수집된 건수를 뜻하지 않습니다. 최근 수집 시각은 수집기 실행 시각으로, 모든 기관의 수집 성공을 보증하지 않습니다.

우선 검토 선정

① 30일 이내 시행 예정인 법령 ② 30일 내 예고종료가 확인된 항목 또는 최근 30일 입법예고 중 자산운용·공통 준법 키워드가 있는 항목 ③ 최근 14일 관련 변경 보도 순입니다. 예고종료일이 지난 협회 예고는 우선 검토에서 제외합니다. 같은 단계에서는 가까운 시행·예고종료일, 최신 게시일 순으로 표시합니다.

자산운용사 관련 후보

제목·담당 부서에서 자산운용, 집합투자, 펀드, 투자신탁, ETF, ETN, 자본시장, 금융투자, 증권, 파생상품, 공매도, 의결권 또는 내부통제, 책무구조도, 지배구조, 금융소비자, 금소법, 자금세탁, 특금법, 전자금융, 개인정보가 발견된 항목입니다. 실제 적용 여부는 원문과 회사 업무를 대조해 판단하세요. 상세에서 일치 키워드를 볼 수 있습니다.

시행일과 의견제출 마감

시행일은 수집된 enf_date만 사용합니다. 없는 시행일을 게시·제개정일로 대체하지 않습니다. 협회 예고는 ‘예고시작일’과 ‘예고종료일’, 협회 제·개정정보는 ‘제·개정일’로 표시합니다. 행정규칙은 ‘발령일’, 법률은 ‘공포일’, 나머지는 ‘게시일’입니다. 과거 시행일은 ‘시행일 경과’이며 현행 유효성을 의미하지 않습니다. 금융위 예고의 의견 마감은 원문 확인이 필요합니다.

금융투자협회 분류

규정 제·개정예고는 입법예고 탭에 통합합니다. 최신 제·개정정보는 협회 현행규정 트리에서 ‘협회규정’ 또는 ‘모범규준’의 하위 규정으로 확인된 항목만 공포/시행 법령 탭에 표시합니다. 표준약관과 현행 트리에서 분류를 확인할 수 없는 항목은 제외합니다. 제목이 아닌 규정 식별번호로 대조하며, 상세에 실제 분류 경로를 표시합니다. ‘모범규준’ 하위의 설명서·가이드라인도 포함됩니다. 협회 규정은 법률과 구분하여 표시합니다.

기존 법령 필터와 확인 기록

법령·규정 필터는 하나씩 선택합니다. 4개 법령은 기존 정밀 제목 규칙을 사용하고 협회규정·모범규준은 협회 현행 분류로 구분합니다. 자료 종류와 법령·규정은 함께 적용됩니다. 자료 종류의 전체 버튼은 자료 종류 조건을 해제하며, 선택한 필터를 다시 누르면 해당 조건만 해제합니다. 필터 초기화로 모든 조건을 해제할 수도 있습니다. 항목 상세를 열거나 원문 링크를 눌러도 자동 확인 처리되지 않습니다. ‘확인 완료’ 버튼을 눌러야 기록되며, 동일 법령의 서로 다른 개정은 별도 항목입니다. 내용이 바뀐 항목은 다시 미확인으로 표시합니다. 기록은 UI 2.0 전용 브라우저 저장소에만 저장됩니다.
